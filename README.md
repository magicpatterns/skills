# Magic Patterns skills

Agent skills. Install with the [skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add magicpatterns/skills
```

One skill:

```bash
npx skills add magicpatterns/skills --skill liquid-glass
```

| Skill | What it does |
| --- | --- |
| [liquid-glass](skills/liquid-glass/SKILL.md) | Liquid Glass UI with `@glass-sdk/liquid-glass` |
